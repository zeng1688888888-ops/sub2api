# 鹈鹕测试

入口：账号管理顶部“鹈鹕测试设置”，以及每个账号测试列下方的“修改提示词”。设置可以反复编辑和保存，不限首次使用。保存只影响下一次测试；历史结果保留实际使用的提示词。

默认保存两条提示词，每次独立随机抽取一条（可能连续重复）：

1. 创建一个 HTML，内容是 SVG 绘制一个鹈鹕骑自行车的 2D 动画，你不需要任何测试，不要读取本地环境和缓存
2. 创建一个 HTML，内容是 SVG 绘制一个秦始皇开坦克的 2D 动画，你不需要任何测试，不要读取本地环境和缓存

可修改文本、添加提示词，或点击“恢复这两条默认提示词”再保存。当前支持最多30条，每条4000字。全局设置保存在原有 account_svg_probe_settings，原有接口保持兼容。

模型通过文本接口生成完整 HTML，内嵌 SVG 和 CSS/SMIL 动画，不调用图片生成接口或工具。单次5分钟超时，同账号同时一个测试，全局最多两个；批量测试逐个执行。生成结果仅供人工观察动作、构图与细节，不自动判定降智。

新结果保存为 DATA_DIR/account-svg-probes/账号ID/结果ID.html，浏览器用无脚本、无同源权限的 sandbox iframe 预览。文档经过 HTML/SVG 白名单重建及 CSP 限制，禁止脚本、事件属性、iframe、外部资源、foreignObject 和跳转。支持内嵌 CSS @keyframes 与 SVG SMIL 动画。旧 .svg 结果仍可预览和下载。每个账号仅保存最近一次结果。

“不要读取本地环境和缓存”等原文属于发给模型的题目要求，不会触发本地文件访问，也不代表关闭上游提示词缓存。

## 测试网络

默认沿用账号的单代理或普通网络（包括本机 TUN），不会使用多出口并发池。若要专门验证并发代理链，可在设置中勾选“使用多出口并发代理池进行测试”。此选项只影响鹈鹕测试，不改账号的正式请求并发池配置。测试结果会保存本次使用的网络类别。

上游流提前断开会标为 stream_interrupted；格式校验错误仍单独标为 invalid_svg。网络中断不等于模型降智，也不代表完整作品已经返回。

## 自动周期

智力测试与鹈鹕测试均在上次测试完成后8分钟到期，后台独立循环每15秒检查，无需打开页面。手动测试仍可随时点击，完成后重置该账号对应测试的到期时间。旧智力记录原有30分钟计划会按最后完成时间重新计算。

自动任务选择 active 的非影子、非模拟 OpenAI OAuth/setup-token 账号；异常或停用账号不自动发起。长动画不会阻塞智力检测。动画全局最多同时2个，同账号同类测试不重复执行，繁忙时排队。分布式主锁避免多个实例同时派发相同的自动批次。

HTML meta 声明会被安全清理，再统一生成UTF-8编码、视口和CSP；不会因为 description、author、color-scheme 等非画面元信息拒绝整个动画。鹈鹕测试到达5分钟或用户取消时直接取消上游，不额外等待普通计费请求的收尾窗口。

## 连续未通过暂停调度

仅非影子、非模拟、非 Agent Identity 的 OpenAI OAuth/setup-token 账号适用。智力测试同一模型及同一路径连续两次明确未通过时，将 schedulable 设为 false，并记录暂停原因。通过、无法判断、网络错误都会中断连续未通过计数；旧 ticket 检测结果不参与。手动与自动智力测试均适用。鹈鹕测试不判分，因此不会触发该暂停。暂停后自动检测继续，但任何后续成功结果都不会自动恢复调度，由管理员手动恢复。该规则不要求 pool_mode 或多出口池。
